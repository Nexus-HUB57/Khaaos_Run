Agenda usada

Para comparar composições, cada habilidade é considerada ativada em t=0 e reutilizada quando o cooldown termina. Um jogador real pode guardar a habilidade e sincronizar a ativação de outro modo.

Como o overlap é calculado

Para cada regra de sinergia, o tempo é a interseção dos intervalos efetivos dos dois operativos: max(0, min(fins) − max(inícios)). “Coberto” é a união temporal dessas interseções; “pair-seconds” soma cada par e pode contar intervalos simultâneos mais de uma vez.

Convenções e escopo

Sinais instantâneos de Ring usam uma janela analítica de 5 s, não uma duração de gameplay. O Pulso de Desarme de Soraya Hadd tem estado de 2 s, mas só 1,5 s de stun efetivo. Reconhecimento, controle e furtividade aplicam-se a bots no runtime local; habilidades ainda não são sincronizadas no online.
