Na raiz de uma cópia limpa do repositório, extraia este pacote em pasta externa:
git switch -c feat/world-graphics-quality
git apply --check /caminho/do/pacote/graphics-upgrade.patch
git apply /caminho/do/pacote/graphics-upgrade.patch
cd game-runtime
npm ci
node --test test/graphics-upgrade.test.js test/perf3d.test.js test/gfxsettings.test.js test/interiors-terrain.test.js
npm test
npm run build
npm run dev

Abra http://localhost:5173/?q=medium&scenario=Arukheea
Settings persistidas podem sobrepor ?q=; use perfil auto ou limpe KR_GFX_SETTINGS_V1.
Reversão na raiz: git apply --reverse --check /caminho/do/pacote/graphics-upgrade.patch
Depois: git apply --reverse /caminho/do/pacote/graphics-upgrade.patch
